# Supplemental rebuttal diagnostics

This directory contains the code, aggregate tables and protocol notes for the
latest safe Phase 4.5 diagnostics: causal ablation, memory-rank sensitivity,
fixed-checkpoint query/observation scaling, equal-wall-clock training and
time-to-quality.

These artifacts are supplemental diagnostics. They do not replace the primary
paper tables and do not establish universal superiority. UEA branch variants,
corrected PhysioNet reruns, event archives, raw data, checkpoints and protected
paper-revision files are intentionally excluded from this anonymous package.
